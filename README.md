# Ход конём — шахматный сайт

Статический сайт: HTML + CSS + чистый JS, без сборки и без сервера. Можно открыть
`index.html` прямо в браузере или захостить через GitHub Pages / любой статический
хостинг.

## Структура

```
index.html        разметка страницы (главная, игра, пазлы, уроки)
style.css         все стили
js/engine.js      базовый движок (генерация ходов, правила, проверено на perft)
js/helpers.js     SAN-нотация, FEN, вспомогательные функции
js/engine2.js     сильный движок: альфа-бета, PST, quiescence, null-move
js/app.js         вся логика интерфейса, состояние партии, пазлы, уроки, рейтинг
data/puzzles.json мат в 1 и мат в 2 ходa для теста на рейтинг
```

## Что работает сразу на любом хостинге

- Игра с ботом (6 уровней силы, свой движок на JS — никакого внешнего ИИ)
- Игра на одном устройстве вдвоём (доска переворачивается)
- Пазлы, уроки, оценка качества ходов (бландер / ошибка / хороший / лучший / бриллиант)
- Тест на рейтинг
- Сохранение прогресса в localStorage браузера

## Без аккаунтов и токенов

Сайт не обращается к Claude и не тратит токены. Оценки ходов и подсказки
считает встроенный движок. Фигуры нарисованы в SVG (спрайт в начале
`index.html`), поэтому выглядят одинаково на всех устройствах.

**Онлайн-игра** (`js/net.js`) работает без регистрации. Игроки встречаются в
«комнате» по коду из пяти цифр на бесплатных публичных MQTT-серверах
(`broker.emqx.io` и `broker.hivemq.com`, подключение сразу к обоим). Каждый
игрок хранит там свой цвет и список ходов. Поэтому после перезагрузки
страницы партию можно продолжить: достаточно снова войти по коду или ссылке.
Публичные серверы открыты всем, поэтому не пишите в игре ничего личного.

Для проверки со своим сервером: `?broker=ws://localhost:8883` в адресе.

## Бот — это движок, не ИИ

Бот в игре — классический шахматный движок (минимакс с альфа-бета отсечением,
таблицами позиционной оценки, quiescence-поиском), написанный с нуля в
`engine2.js`. Он не использует языковую модель и не обращается ни к какому
ИИ-сервису — считает варианты сам, как Stockfish упрощённого уровня.

## Запуск локально

Просто открыть `index.html` в браузере — не нужен сервер.
Для деплоя на GitHub Pages: включить Pages в настройках репозитория, указать
ветку и корень `/`.
