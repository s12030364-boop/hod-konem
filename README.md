# Ход конём — шахматный сайт

Статический сайт: HTML + CSS + чистый JS, без сборки и без сервера. Можно открыть
`index.html` прямо в браузере или захостить через GitHub Pages / любой статический
хостинг.

## Структура

```
index.html        разметка страницы (главная, игра, пазлы, уроки, тренер)
style.css         все стили
js/engine.js      базовый движок (генерация ходов, правила, проверено на perft)
js/helpers.js     SAN-нотация, FEN, вспомогательные функции
js/engine2.js     сильный движок: альфа-бета, PST, quiescence, null-move
js/app.js         вся логика интерфейса, состояние партии, пазлы, уроки, рейтинг
data/puzzles.json мат в 1 и мат в 2 ходa для теста на рейтинг
```

## Что работает сразу на любом хостинге

- Игра с ботом (6 уровней силы, свой движок на JS — никакого внешнего ИИ)
- Игра на одном устройстве вдвоём (доска переворачивается)
- Пазлы, уроки, оценка качества ходов (бландер / ошибка / хороший / лучший / бриллиант)
- Тест на рейтинг
- Сохранение прогресса в localStorage браузера

## Что НЕ работает вне claude.ai — и что с этим делать

В коде есть два места, которые вызывают `window.claude.use(...)` — это API
платформы Claude Artifacts, доступное только внутри артефактов на claude.ai.
На обычном сайте (GitHub Pages и т.п.) `window.claude` не существует, и код
это уже корректно обрабатывает (см. `js/app.js`, строки ~64–69) — ничего не
ломается, просто эти две функции выключаются:

1. **Тренер-чат** (`window.claude.use('sample')`) — это и есть объяснения
   ходов от Claude (меня) внутри игры. Без этого API чат с тренером просто
   говорит «недоступен в этом просмотре»; разбор хода по шаблонным правилам
   (оценки ходов, подсказки) работает без него.

   Чтобы вернуть живые объяснения на своём сайте, нужен собственный backend:
   небольшой сервер (например, на Node/Python), который принимает вопрос от
   страницы, обращается к Claude через Anthropic API (нужен свой API-ключ,
   https://docs.claude.com) и возвращает ответ. Функцию `ask()` в
   `js/app.js` нужно переписать, чтобы она звала этот backend вместо
   `window.claude.use('sample')`. Я могу сделать такой backend, если нужно —
   это отдельная задача (ключ API, деньги за токены — твои).

2. **Онлайн-игра между двумя людьми** (`window.claude.use('room')`) — тоже
   особенность платформы claude.ai (realtime-комнаты по коду). Вне неё нужен
   свой сервер синхронизации партии (WebSocket либо Firebase/Supabase
   realtime и т.п.). Игра вдвоём на одном устройстве продолжит работать без
   этого.

## Бот — это движок, не ИИ

Бот в игре — классический шахматный движок (минимакс с альфа-бета отсечением,
таблицами позиционной оценки, quiescence-поиском), написанный с нуля в
`engine2.js`. Он не использует языковую модель и не обращается ни к какому
ИИ-сервису — считает варианты сам, как Stockfish упрощённого уровня. А вот
тренер (объяснения ходов) — это я, Claude, через API платформы (пункт 1 выше).

## Запуск локально

Просто открыть `index.html` в браузере — не нужен сервер.
Для деплоя на GitHub Pages: включить Pages в настройках репозитория, указать
ветку и корень `/`.
